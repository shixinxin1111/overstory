# Overstory 第一版验收

本页记录旧版验收。2026-11-22 的界面重做、整行排序和独立更新包的验证结果见 [界面重做记录](redesign.md#已实施与验证2026-11-22)；旧版结果不代表新版原生验收通过。

验收日期：2026-11-22。目标环境：当前 Apple Silicon Mac，macOS 原生 Tauri 应用。

## 自动检查

- `pnpm build`：通过。TypeScript 编译与 Vite 生产构建成功，生产包不包含开发预览数据。
- `cargo fmt --check` 和 `cargo check`：通过。
- `cargo test`：6 项通过，0 项失败。
- `pnpm tauri build --bundles app`：通过，生成本机 `.app`。

Rust 检查覆盖：

1. 串行写入、完成状态与手动顺序相互独立。
2. 跨组移动、删除分组保留内容、备份恢复保留顺序。
3. 写入失败保持内存中的权威数据不变。
4. 主数据损坏时恢复有效副本；无法恢复时阻止覆盖原文件。
5. 无效备份不修改当前数据，未知模块命名空间被保留。
6. 负坐标显示器、屏幕移除后的窗口边界修正。

验收过程中桌面操作通道返回 `SDK error: ordinary desktop lock state changed`，一次重新观察仍返回同样错误，后续界面操作停止。未通过其他方式绕过桌面锁。

实测还发现小球的辅助功能 AX 点击未触发展开，鼠标坐标点击正常。源码已改为标准按钮 `onClick`，保留拖动后抑制误点击；补强版本构建到 `release/pending/Overstory.app`。该版本尚未替换当前运行的应用，也尚未进行原生复验。

两条中文验收待办保留在当前应用数据中，未通过 GUI 删除数据。

以下原生场景仍待验收：小球实际移动及位置恢复、面板／主窗互斥和关闭回球、失焦保持、实际网页打开、网页／便签增改与跨组拖拽、分组与导航排序、便签自动保存及切换交接、导入导出 UI、重启恢复、快速切换和动画中断。上述功能已有实现，未实测的场景不计为通过。
