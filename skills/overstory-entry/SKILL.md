# Overstory 技能入口

使用能在用户这台 Mac 上执行命令的工具；在豆包工作中选择“本地电脑”。

每个新任务先执行：

```sh
/usr/local/bin/overstory skill show
```

读取命令输出的完整技能说明，再按该说明使用本机 CLI 完成用户任务。每次任务重新读取，软件升级后以本次 CLI 输出为准，不缓存上次的说明。这个命令只读取内置说明，不打开或修改业务数据。

如果提示命令或 `skill` 子命令不存在，说明需要安装/升级包含配套 CLI 的 Overstory，或在 App 设置 → 命令行工具中安装/升级，然后继续原任务。不要自行安装、使用 sudo、重启 App、修改数据文件或下载执行其他程序。云端环境无法访问用户的本机数据，应切换到本地电脑任务。
