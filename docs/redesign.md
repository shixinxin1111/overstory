# Overstory 界面重做

用户否定第一版视觉，并要求先参考 Apple 官方资料再实施。最新要求允许取消排序锚点，本次直接取消所有可见点阵锚点，采用整行拖动。

## 官方依据

- [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：玻璃是导航和控件的功能层，不能铺满内容层。标准材质承担正文的层级区分。
- [Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)：控件按功能分组，减少背景与染色，标题帮助定位内容；备忘录正文不重复标题。
- [Sidebars](https://developer.apple.com/design/human-interface-guidelines/sidebars)：侧栏支持自定义顺序，控制层级，精简标签，尺寸不足时采用紧凑导航。
- [Adopting Liquid Glass](https://developer.apple.com/documentation/technologyoverviews/adopting-liquid-glass/)：减少自定义背景、注意同心圆角、保证可读性及辅助功能。
- [Build an AppKit app with the new design](https://developer.apple.com/videos/play/wwdc2025/310/)：标题栏、工具栏、分栏和内容形成完整窗口；玻璃只承载交互控件，正文以边到边的布局展开。
- [Notes User Guide](https://support.apple.com/guide/notes/welcome/mac)：参考备忘录的信息架构及纸面编辑体验。

已实际查看 Apple 官方备忘录工具栏截图。概念图在 `design-reference/`，用于材质和整体关系研究，不作为应用内图片。图像生成中的超大字号、重复“便签”标题、粗重图标、列表卡片与比例偏差明确排除；下面的尺寸规格与官方原生示例优先。

## 实施规格

### 窗口与层级

- 保留 56 × 56 小球、380 × 520 面板、1040 × 720 主窗及既有数据生命周期。
- 主窗使用原生交通灯、透明叠加标题栏，正文延伸到窗口顶部；统一的 52–56px 工具栏替换旧版标题栏下的口号栏。
- 侧栏约 184px，便签列表约 264px，其余为白色编辑区；各栏用一根低对比分隔线分开，编辑区没有嵌套卡片。
- 小球换为清透、浅色光学表面，深色数字或极简符号；取消蓝色金属珠质感。静置不循环播放动画。
- 面板使用克制的磨砂导航外壳、24px 外圆角和同心控件，正文保持近白色且清楚可读。
- 可使用系统窗口材质和阴影，所有应用内控件、图标和排序仍手写；不新增第三方 UI 库。

### 内容与排版

- 使用系统 SF/PingFang 字体，正文 13px，辅助文字 11px，侧栏 13px，文档标题 24px；杜绝把界面做成大字展示页。
- 侧栏只保留必要导航和设置，去掉大品牌区、口号、装饰球和底部文学文案。
- 便签列表用标题、实际更新时间和正文摘要形成层级；选中项使用轻柔浅金色，其他项不包卡片。
- 编辑区直接呈现日期、标题和正文，删除仅作为工具栏图标动作；已保存／保存中保持尺寸稳定。
- 空数据只保留一个主要空态。空分组用短小占位接收跨组拖动，不再与巨大列表空态叠加。
- 待办移除装饰图标块和营销式标题，采用细致复选圆圈、紧凑筛选、整洁行距。
- 网页选择、打开、编辑保持独立；减少图标底板和大面积蓝色 CTA。
- 表单按钮保持紧凑系统控件尺度；只有确认保存等关键动作使用强调色。

### 排序与交互

- 待办、网页、便签、分组和导航取消可见锚点，拖动整体排序。
- 输入框、正文编辑器、选择器、复选框及编辑／删除／打开按钮不触发排序。
- 拖动超过阈值才开始；正常单击保持原有行为；拖动结束后的点击被抑制，避免误编辑、误打开或导航。
- 保留跨空组／折叠组、组选择器悬停、自动滚动、Esc 取消、搜索禁排序、排序持久化和过期 revision 保护。
- 可排序行支持键盘操作，通过可访问的行焦点提供原有拾起、方向键、放置、取消能力。
- 导航选中胶囊、排序移位、完成勾选、数字变化、弹层与形态切换使用统一短时弹簧。静态秩序优先，不堆叠持续光效。

### Apple 官方依据及颜色检查

已实际读取 [Color](https://developer.apple.com/design/human-interface-guidelines/color)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[SF Symbols](https://developer.apple.com/design/human-interface-guidelines/sf-symbols) 官方指南。采用少量颜色表达一致语义、突出少数主动作、保留文字与图形状态，并对浅色、深色、增强对比度分别设置 CSS 变量。这里使用手写 CSS 和 SF Symbols SVG，不声称接入 AppKit 动态 NSColor。

常规颜色在实际定义背景上的计算对比度：浅色蓝／白 5.28:1，浅色收藏金／白 5.14:1，浅色辅助文字／白 5.60:1；深色蓝／正文背景 7.26:1，深色收藏金／正文背景 8.95:1。主按钮采用深蓝底配白字。选中状态同时保留 `aria-current`／`aria-pressed`，完成同时显示勾形与删除线，收藏采用实心星，不仅凭颜色区分状态。这些是定义颜色的静态计算，不代表完整屏幕的无障碍审计。
